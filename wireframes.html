Career trajectory + certifications — 3 treatments

~ your chosen: subway/circuit, + 2 more to compare

Roles (5 since 2020) and certs (10 since 2020) share the same time axis. Three ways to render that overlap — each carries cyberpunk motifs differently.

TIMELINE · T1CIRCUIT / SUBWAY ★
Two rails: roles ═ certs. Bridges where a cert unlocked a role.
  • Scroll ↓ advances a glowing cyan "read-head" along both rails
  • Hover a node → projects/tags fly in from the margins
  • Dashed bridges = causal links (e.g. Databricks cert → ASML role)
  • Pick this one. Matches your brief exactly.
TIMELINE · T2VERTICAL SCROLL
Linear, scroll-synced. Card flips to show project wins.
  • Simplest to read — safest default
  • Each card expands on click for details
  • Certs stacked as chips inside each role
  • Works but loses the "system diagram" feel you want
TIMELINE · T3HORIZONTAL TRACK
Drag left ↔ right. Feels like a mission log.
  • Pins to top, horizontal scroll hijacks vertical
  • Beautiful on desktop, awkward on mobile
  • Most cinematic · highest implementation cost
  • Fallback to T2 on narrow viewports

STACK · S1FORCE GRAPH ★
Live simulation. Click a node → projects using it light up.

Honeycomb grid. Brighter = more experience.
  • Filter bar above: [cloud] [data] [ops] [lang] [gov]
  • Cells fade based on active filter
  • Most scannable · less "live system" feeling
  • Best if you add logos later
